# Contributing to NexusCore Enterprise

Thank you for your interest in contributing to NexusCore Enterprise! We welcome contributions from developers of all skill levels.

## How to Contribute

### 1. Fork the Repository
- Click the **Fork** button at the top right of the repository page to create your own copy of the repository.
- Clone your forked repository to your local machine:
  ```bash
  git clone https://github.com/YOUR_USERNAME/nexuscore-enterprise.git
  cd nexuscore-enterprise
  ```

### 2. Local Environment Setup
- To set up the local development environment and start the services, run:
  ```bash
  make up
  ```

### 3. Running Tests
- Before submitting your changes, make sure all tests pass by running:
  ```bash
  make test
  ```

### 4. Submitting a Pull Request (PR)
- Create a new branch for your feature or bug fix:
  ```bash
  git checkout -b feature/your-feature-name
  ```
- Commit your changes with a clear commit message.
- Push your branch to your forked repository:
  ```bash
  git push origin feature/your-feature-name
  ```
- Open a Pull Request against the `main` branch of `mzb000/nexuscore-enterprise`.
- Fill out the Pull Request template with all relevant details.

Thank you for helping make NexusCore Enterprise better!
